# 🏦 Sistema Bancário em Python (POO)

Um sistema bancário via terminal desenvolvido inteiramente em Python. Este projeto foi criado para aplicar e consolidar os conceitos fundamentais de **Programação Orientada a Objetos (POO)**, garantindo um código estruturado, modular e de fácil manutenção.

## 🎯 Funcionalidades e Conceitos Aplicados

O sistema simula operações bancárias reais através do terminal, utilizando:

*   **Classes e Objetos:** Estruturação das entidades do banco (ex: `Conta`, `Cliente`).
*   **Encapsulamento:** Proteção de dados sensíveis, como o saldo da conta, permitindo alterações apenas através de métodos específicos (saques e depósitos).
*   **Métodos Personalizados:** 
    *   💵 Realizar depósitos.
    *   💸 Efetuar saques (com validação de saldo e limites).
    *   🧾 Consultar extrato e saldo atual.

## 🚀 Tecnologias Utilizadas

*   **Linguagem:** Python 3
*   **Paradigma:** Programação Orientada a Objetos (POO)

## 📁 Estrutura do Repositório

*   `banco.py`: Arquivo principal contendo todas as classes, métodos e a lógica de execução do sistema bancário via terminal.
*   `README.md`: Documentação explicativa do projeto.

## ⚙️ Como executar o projeto localmente

Como o projeto é um script puro em Python, a execução é feita de forma muito simples diretamente no terminal da sua máquina.

1 - Clone este repositório:
```bash
git clone [https://github.com/andrei817/Sistema_Bancario_POO.git](https://github.com/andrei817/Sistema_Bancario_POO.git)
```
2 - Entre na pasta do projeto
``` python
cd Sistema_Bancario_POO
```
3 - Execute o script python
``` python
python banco.py
```
